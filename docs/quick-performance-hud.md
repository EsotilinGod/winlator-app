# Acceso rápido al HUD

Durante una sesión, abre el menú lateral con el botón Atrás de Android o con
un toque de cuatro dedos. La opción **Mostrar HUD de rendimiento** activa el
medidor sin cerrar el juego; la misma opción cambia a **Ocultar HUD de
rendimiento** mientras está activo.

El cambio solo dura durante esa sesión y no modifica el modo guardado en el
contenedor. Si el contenedor arranca con el HUD desactivado, el acceso rápido
usa el modo Avanzado. Si arranca en Simple, Completo o Avanzado, recuerda ese
modo al ocultarlo y volverlo a mostrar.

La descripción de la GPU se solicita al iniciar el contenedor para que también
esté disponible cuando el HUD se active más tarde. Esto no habilita muestreo
continuo de uso de GPU.
